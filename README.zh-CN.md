# Mole App

[English](README.md)

这里是 **Mole for Mac** 和 **Mole for Windows** 的官方文档与反馈仓库，可以了解产品、提交问题和参与讨论。

**Mac 和 Windows App 都没有开源**，这个公开仓库只存放产品说明和社区反馈表单，不包含 App 源码，开源的命令行工具在独立的 [Mole CLI 仓库](https://github.com/tw93/Mole)。

## 常见问题

### GitHub 仓库公开，是不是意味着 App 开源了？

不是，这里公开的是文档和反馈入口，Mac 与 Windows App 的源码仍然私有，公开这些文档不代表公开 App 源码或授予源码使用许可。

### 用 App 之前需要安装 CLI 吗？

不需要，Mole for Mac 和 Mole for Windows 都可以独立运行，安装 CLI 也不会安装这两个 App。

### App 是免费的吗？

App 采用一次性付费授权，当前价格、试用和退款说明可以在各自的官网查看，开源 CLI 免费。

### 更详细的说明在哪里？

[Mac 帮助中心](https://mole.fit/zh/help)和 [Windows 帮助中心](https://mole.fit/zh/windows/help)提供完整使用指南，文章里也有清理、卸载、磁盘空间等常见问题的说明，下载和最新产品信息以官网为准。
