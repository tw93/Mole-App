# Mole App

[简体中文](README.zh-CN.md)

Official documentation, issue reports and discussions for **Mole for Mac** and **Mole for Windows**, the desktop apps for cleaning and managing your computer.

**The Mac and Windows apps are closed source.** This public repository contains product information and community feedback forms. It does not contain application source code. The separate [Mole CLI](https://github.com/tw93/Mole) is open source.

## Get Mole

| App | Requirements | Download | User guide |
| --- | --- | --- | --- |
| Mole for Mac | macOS 14 or later, Apple Silicon or Intel | [Mac website](https://mole.fit/) | [Mac help](https://mole.fit/help) |
| Mole for Windows | Windows 10 22H2 or Windows 11, x64 or ARM64 | [Windows website](https://mole.fit/windows) | [Windows help](https://mole.fit/windows/help) |

Both apps bring cleanup, app management, maintenance, disk analysis and live system status into one interface.

## FAQ

### Does a public GitHub repository mean the apps are open source?

No. GitHub hosts the public documentation and feedback here. The Mac and Windows application source code remains private. Making these documents public does not publish or license the application source code.

### Do I need to install the CLI to use the apps?

No. Mole for Mac and Mole for Windows are standalone desktop apps. Installing the CLI does not install either app.

### Are the apps free?

The apps are paid products with one-time licenses. Each product website has its current pricing, trial and refund details. The open-source CLI is free.

### Where can I find detailed instructions?

The [Mac help center](https://mole.fit/help) and [Windows help center](https://mole.fit/windows/help) have the full guides. Their article collections cover cleanup, uninstalling apps, disk space and other common questions. The official website is the main source for downloads and current product information.
